# Testing notes

The prior project conversation records successful baseline PDF/image watermark round trips and CNN robustness tests on the generated validation set. It also records failures in exact watermark extraction under some severe image transformations.

Existing independent CNN test analyses showed false positives at threshold 0.5 and a trade-off between false positives and detection rate as the threshold increased. The threshold selected from the same test set should not be described as independently validated.

The current bundle does not contain the latest independent CSV files because those files were not present in the available workspace at packaging time.
